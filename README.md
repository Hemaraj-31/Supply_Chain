OptiStock – Supply Chain & Inventory Optimization Dashboard
📌 Project Description

OptiStock is a Power BI dashboard designed to analyze inventory performance and demand trends.
It helps organizations reduce stockouts and overstock by providing key supply chain insights.

🛠 Tools & Technologies

Power BI

DAX

Excel / CSV Dataset

Data Modeling (Star Schema)

📊 Key Features

Inventory Overview Dashboard

Inventory Health Analysis

Demand Forecast Visualization

KPI Cards (Inventory Value, Stock Turn, Sell-Through Rate, On-Time Delivery)

Interactive slicers (Category, Warehouse)
